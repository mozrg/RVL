Как установить RVL?

Скачай ZIP, распакуй его целиком в отдельную папку и запусти RVL.exe. Не запускай EXE прямо из архива.

Окно не открывается — что делать?

Установи .NET 8 Desktop Runtime x64 и Microsoft Edge WebView2 Runtime, затем запусти RVL.exe ещё раз.
