# RVL — Private VIP Launcher

Быстрый лаунчер приватных серверов Roblox для Windows. Сохраняйте сервера как
пресеты и запускайте их в одно нажатие, горячей клавишей без
поиска ссылок и копипаста.

![RVL](images/rvl.png)

---

## Новая нативная версия

В папке [`app/`](app/) находится обновлённый клиент RVL без AutoHotkey и
ActiveX/IE. Он использует тот же существующий HTML/CSS/JS-интерфейс с
небольшими визуальными правками, а C# host сохраняет функционал старой версии:
пресеты, группы, темы, историю, аватарки, backup, обновления и горячие клавиши.

Для запуска нужны .NET 8 Desktop Runtime и Microsoft Edge WebView2 Runtime:

```powershell
dotnet run --project app/RVL.csproj
```

Lean Release-пакет вместе с UI занимает около 2–3 МБ без системных runtime.
Старый AHK-клиент ниже оставлен как legacy-совместимость.

## Возможности

- **Пресеты серверов** — два способа запуска:
  - **СП 1**: Place ID + Link Code приватного сервера;
  - **СП 2**: share-код (ссылка «скопировать ссылку на сервер») или прямая ссылка с configure private server.
- **Мгновенный запуск** — через протокол `roblox://` (установленный клиент);
  если клиент не зарегистрирован — автоматический fallback в браузер.
- **Горячие клавиши**: глобальная (по умолчанию F4), показать/скрыть окно,
  отдельная клавиша на каждый пресет.
- **Счётчики запусков** и время последнего запуска, статистика (всего, за
  неделю, средний интервал, топ пресетов, график за 7 дней).
- **Избранное и группы** пресетов, сортировка, поиск, вид список/сетка.
- **Аватарки игр** в панели пресета — реальные обложки с Roblox, кэшируются
  на диск в папку `images/av`. Загрузку аватарок можно полностью отключить
  в настройках, а кнопка «Удалить все аватарки» очищает весь кэш.
- **Автозапуск при старте системы** (галочка в настройках).
- **Внешний вид**: тёмная/светлая тема, свои цвета и градиенты, масштаб,
  прозрачность, компактный режим, «поверх всех окон», настройка видимых
  элементов интерфейса.
- **Два языка**: русский / английский.
- **Обновления**: автоматическая проверка при запуске через GitHub Releases,
  скачивание и установка в один клик.
- **Импорт/экспорт** пресетов, групп и цветовых пресетов, полная резервная
  копия (`.rvlbackup`), сброс к заводским настройкам.
- **История запусков** (`data/history.log`).

## Legacy: установка и запуск AHK-версии

1. Установите [AutoHotkey v1.1](https://www.autohotkey.com/) (проверено на
   v1.1.37). Нужна именно **ветка 1.1**, не v2.
2. Скопируйте папку проекта в любое место (путь может содержать кириллицу и
   OneDrive — это поддерживается).
3. Запустите `RVL.ahk` (двойным кликом или через AutoHotkeyU64.exe).

Требования: Windows 10/11, установленный Roblox (или любой браузер как
fallback), интернет для аватарок и проверки обновлений.

## Как пользоваться

### Добавить сервер

1. Перейдите в игру Roblox и создайте/откройте приватный сервер.
2. **Способ 1** — вкладка «СП 1»:
   - *Place ID* — число из адреса игры: `roblox.com/games/`**`133410800847665`**`/...`;
   - *Link Code* — параметр `linkCode` из ссылки приватного сервера
     (длинное число) или `хэш&type=Server` из кнопки «Копировать ссылку».
3. **Способ 2** — вкладка «СП 2»: вставьте share-код — часть ссылки
   `roblox.com/share?code=`**`e8e3674fce...`** после `code=` (код можно
   вставить целиком ссылкой — лишнее отрежется).
4. Нажмите «ЗАПУСТИТЬ» (запустит и предложит сохранить пресет) или иконку
   сохранения.

### Запуск

- Кнопка «ЗАПУСТИТЬ» с заполненными полями;
- клик по пресету в списке;
- горячая клавиша пресета (назначается в панели пресета или в настройках);
- глобальная клавиша (по умолчанию F4) — запускает выбранный пресет.

### Панель пресета

Клик по пресету открывает панель: аватарка игры, счётчик запусков, время
последнего запуска, избранное, назначение горячей клавиши, редактирование,
дублирование, удаление (с отменой).

### Настройки

- **Поведение**: скрыть окно после запуска, подсказки, маскировка вводимых
  данных, поверх всех окон, компактный режим, **автозапуск при запуске
  системы**, задержка перед запуском.
- **Внешний вид**: масштаб, прозрачность, темы и цвета, градиент фона.
- **Горячие клавиши**: глобальный запуск и показать/скрыть окно.
- **Импорт/экспорт** пресетов и цветовых пресетов, **резервная копия**,
  **сброс к заводским** (удаляет пресеты, настройки и ключ автозапуска).
- **Обновление**: кнопка проверки; при найденной новой версии — диалог
  «Обновить/Позже», прогресс и автоматический перезапуск.

### Автозапуск

Галочка в настройках создаёт/удаляет запись
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\RVL` (пути в кавычках).
Если удалить запись вручную через Диспетчер задач, RVL не станет возвращать
её сам — до следующего переключения галочки.

## Как это работает (архитектура)

```
RVL.ahk                 хост: окно, мост с UI, горячие клавиши, запуск
│                       Roblox, конфиг, система обновлений, реестр
├─ ui/index.html        разметка (одно окно = главное + настройки + гайд)
├─ ui/app.js            вся логика интерфейса (ES5, движок IE)
├─ ui/style.css         стили
├─ ui/messages.txt      русские строки хоста (UTF-8, ключ=значение)
├─ update/
│  ├─ update-worker.ps1    скачивание/распаковка/замена файлов обновления
│  ├─ update-helper.ps1    визуальный прогресс обновления
│  └─ fetch-icon.ps1       воркер аватарок (Roblox API → PNG)
├─ data/                пользовательские данные (создаются на месте)
│  ├─ config.ini           настройки
│  ├─ presets.json         пресеты
│  ├─ theme_presets.json   цветовые пресеты
│  ├─ preset_groups.json   группы
│  └─ history.log          журнал запусков
└─ images/              логотип, иконка и кэш аватарок (`images/av/`)
```

### Запуск интерфейса

При старте `RVL.ahk` собирает **один комбинированный HTML**: инлайнит
`style.css` и `app.js` в `index.html`, переписывает адрес картинок в
абсолютные `file:///`-пути, кладёт результат в `%TEMP%\RVL_ui.html` и
открывает его в ActiveX `Shell.Explorer` (движок IE). Отдельная копия с
суффиксом `#settings-native` обслуживает отсоединяемое окно настроек.
Поэтому «сайт» не нужен — всё работает локально из одного файла.

### Мост AHK ↔ JS

UI и хост общаются через скрытые `<input>`-поля:

- `__cmd_queue` — **JS → AHK**, очередь команд `CMD:...\n` (запуск, сохранение,
  проверка обновления, переключатели и т.д.). AHK разбирает её каждые 50 мс,
  каждая команда изолирована своим `try` — сбой одной не роняет очередь.
- `__thumb_resp` — **AHK → JS**, очередь ответов `key|path\n` с путями
  аватарок (симметричная очередь: AHK дописывает, JS вычитывает и чистит).
- `__update_state / __update_message / __update_progress / __update_version`
  — состояние обновления, которое JS отображает (сплэш, карточка, оверлей).
- `__cfg_*` — текущие значения настроек (конфиг → UI при старте, UI → конфиг
  при сохранении).

Таймеры хоста: `ProcessCommands` (50 мс), `PollJSCmd` (20 мс), обновление
статуса Roblox (2 с), опросы установщика (100 мс).

### Запуск сервера

`LaunchRoblox()` проверяет регистрацию протокола `roblox://` в реестре:

- есть клиент → `roblox://experiences/start?placeId=...&linkCode=...`
  (для share-кодов — `roblox://navigation/share_links?code=...`);
- нет → браузер: `https://www.roblox.com/games/<id>/?linkCode=...` или
  `https://www.roblox.com/share?code=...`.

Каждый запуск дописывается в `data/history.log`.

### Аватарки игр

JS просит `CMD:thumb_req <ключ>` (place id или `sc:<код>`). Хост отвечает
мгновенно из дискового кэша `images/av/RVL_icon_<ключ>.png`, иначе запускает
скрытый воркер `update/fetch-icon.ps1`: share-страница → place id →
universe id → `thumbnails.roblox.com` → PNG. Ответы возвращаются очередью в
`__thumb_resp`; неудачи повторяются через 90 с, «подвисшие» — через 20 с.
Сеть при этом никогда не блокирует интерфейс.

Загрузку аватарок можно выключить в настройках (тумблер «Загружать аватарки
игр») — тогда панель пресета показывает порядковый номер вместо обложки и
никаких запросов в сеть не уходит. Кнопка «Удалить все аватарки» очищает
весь кэш в `images/av` (старый кэш из `%TEMP%` мигрирует туда при запуске и
тоже удаляется).

Старые закэшированные файлы из `%TEMP%\RVL_icon_*` автоматически
переносятся в `images/av` при первом запуске новой версии.

### Обновления

`OnCheckUpdate` опрашивает GitHub API (`releases/latest`, список релизов,
теги — выигрывает самая свежая числовая версия), сравнивает с `APP_VERSION`
и публикует состояние в UI. Установка: воркер `update-worker.ps1` скачивает
zip с `codeload.github.com`, распаковывает, заменяет все файлы **кроме
`data\`** (пользовательские данные не трогаются) и перезапускает RVL.
Есть резервный путь обновления силами самого хоста. Сообщения об ошибках
честные: недоступность GitHub показывается как ошибка, а не «у вас последняя
версия».

### Кодировки — важно для разработчиков

- `RVL.ahk` может быть сохранён в любой кодировке: **никогда не вписывайте
  русские строки литералами в скрипт**. Без BOM AHK v1 читает файл в cp1251,
  и строки ломаются на пути к DOM.
- Все строки хоста лежат в `ui/messages.txt` и читаются через
  `FileRead *P65001` (функция `UiMsg("ключ", "english fallback")`).
- Файлы `ui\*` тоже читаются с `*P65001`.
- `update-worker.ps1` / `update-helper.ps1` сохранены как **UTF-8 с BOM**
  (требование PowerShell 5.1 для кириллицы).

## Диагностика

| Проблема | Что смотреть |
|---|---|
| Аватарки не грузятся | `%TEMP%\RVL_thumb_debug.txt` — весь путь запроса (`hit/req/launched/FAIL`). Сбросить кэш: кнопка «Удалить все аватарки» в настройках или удалить папку `images/av/` (при закрытом RVL) |
| «Не удалось связаться с GitHub» | Доступность `api.github.com`; лимит 60 запросов/час без токена |
| Настройки «слетели» | `data\config.ini`; полный сброс — удалить папку `data\` (при закрытом RVL) |
| Обновление не ставится | `%TEMP%\RVL_update_status.txt`, файлы `RVL_update_worker_*.ps1` |
| Окно не появляется | Проверьте, что `RVL.ahk` запущен именно AutoHotkey **v1.1**, а не v2 |

Лог аватарок и проверок версии пишется в `%TEMP%\RVL_thumb_debug.txt` (UTF-8).

## Структура версии

Версия задаётся в `RVL.ahk` (`APP_VERSION`). Релиз = тег вида `1.13` в
репозитории `mozrg/RVL`; теги без числового формата обновлением не
считаются.
